# lucycookdesigns.com — Webflow archive

**View it live:** https://loosecookie.github.io/lucycookdesigns-portfolio-V6-webflow/

A static mirror of the Webflow-hosted version of lucycookdesigns.com (`lucycookdesigns.webflow.io`), archived here after moving off a paid Webflow plan.

All pages, stylesheets, scripts, and images were downloaded as-is so the site can still be viewed or redeployed without a Webflow subscription. No content has been edited beyond removing `integrity`/`crossorigin` attributes that no longer matched the re-saved assets.

Superseded by the current build in [lucycookdesigns-website](https://github.com/loosecookie/lucycookdesigns-website).
